# MYPORTFOLIO

> **Vivek Singh** — Backend & Distributed Systems Engineer  
> B.E. in Electronics & Telecommunication (2023–2027), Army Institute of Technology (AIT), Pune.

An editorial, high-performance portfolio crafted with **Next.js 14**, **Tailwind CSS**, and **Framer Motion**, engineered around an obsidian dark aesthetic inspired by modern architectural design, interactive canvas wave physics, and smooth scroll mechanics.

---

## ⚡ Highlights

- **Obsidian Editorial Theme:** Deep `#030303` backdrop with bone-white typography (`Instrument Serif` & `DM Sans`) and subtle Sunset Amber (`#FF8C59`) accents.
- **Growing Hero Scroll Effect:** Interactive 3D mouse parallax and physics-based portrait zoom anchored to the face on scroll.
- **Particle Signal Wave Canvas:** Dynamic mathematical particle field responding to viewport motion and scroll expansion.
- **Interactive Terminal Console:** Built-in interactive shell (`help`, `skills`, `projects`, `benchmark`, `contact`, `clear`) simulating an authentic developer console with real-time microservices status and simulated load testing.
- **Architecture Deep-Dives:** Comprehensive technical cards featuring custom hand-crafted SVG blueprints:
  - **SmartDoc AI:** Local RAG platform with RediSearch KNN vector semantic caching (~147x latency improvement, 28ms hit), pgvector HNSW search, and Ollama offline inference.
  - **AI Video Assistant:** 6-stage multimodal RAG pipeline with Whisper bilingual ASR, ChromaDB vector indexing, and structured summarization.
  - **TradeX:** Distributed crypto trading engine with dual Priority Queue matching, Spring Cloud API Gateway, Netflix Eureka, and asynchronous Kafka settlement.
  - **Ride-Sharing System:** Real-time geospatial dispatch with Redis GEO (<50ms lookups), WebSocket streaming, and transactional driver state management.
- **Smooth Kinematics:** Powered by Lenis smooth scrolling with physics damping.

## 🛠 Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router, Server & Client Components)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) with curated CSS tokens
- **Animations:** [Framer Motion](https://www.framer.com/motion/) & [Lenis](https://lenis.darkroom.engineering/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Image Processing:** [Sharp](https://sharp.pixelplumbing.com/)

## 🚀 Getting Started

### Prerequisites

- Node.js 18.17+ or higher
- npm / yarn / pnpm

### Installation

```bash
# Clone repository
git clone https://github.com/FABvivek/MYPORTFOLIO.git
cd MYPORTFOLIO

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
# Build production bundle
npm run build

# Start production server
npm run start
```
